# Tooling

Everything ships in one `velt` binary.

| Page | Covers |
|---|---|
| [The `velt` command](/docs/tooling/cli/) | `build`, `run`, `check`, `test`, `new`, `init`, `doc`, `toolchain`, `doctor`, the build cache, completions, environment variables |
| [`velt dev`](/docs/tooling/dev/) | hot reload: hot swap and restart on save, socket handover |
| [`package.velt`](/docs/tooling/manifest/) | the package manifest, dependencies, `paths` aliases, the lockfile |
| [Packages and registries](/docs/tooling/packages/) | `add`, `install`, `update`, `publish`, git dependencies, workspaces, npm packages, the official packages, registry servers |
| [Formatter](/docs/tooling/fmt/) | `velt fmt` |
| [Editors](/docs/tooling/editors/) | the language server and the VS Code extension |
| [Debugging](/docs/tooling/debugging/) | debug info, LLDB, GDB, Visual Studio, VS Code |
| [WebAssembly](/docs/tooling/webassembly/) | WASI and browser targets, the playground |
| [Platforms and installation](/docs/tooling/platforms/) | supported platforms, prerequisites, distributions |

Testing is covered in the Book: [Testing](/docs/book/testing/). The SQLite, PostgreSQL and Redis
drivers and the HTTP server are [packages](/docs/packages/).
