# The Velt Book

The Book teaches Velt from the ground up, with an eye on what is new if you come from
TypeScript. Every Velt code block in it is compiled by the documentation tests.

## Getting started

1. [Getting started](/docs/book/getting-started/): install, your first program, project layout
2. [A tour of Velt](/docs/book/tour/): the whole language in one page
3. [Velt for TypeScript developers](/docs/book/ts-developers/): every difference, and why

## Guides

- [Building an HTTP server](/docs/book/http-server/): routing, JSON, validation, shared state, tests
- [Building a command-line tool](/docs/book/cli-app/): arguments, files, exit codes, tests
- [Server-rendered pages with TSX](/docs/book/ssr-pages/): components, lists, layouts, async data, streaming
- [Async and concurrency](/docs/book/async/): promises, timeouts, `spawn`, shared state
- [Error handling](/docs/book/errors/): typed `catch`, `throws` clauses, errors as values, panics
- [Memory without a garbage collector](/docs/book/memory/): JavaScript's object semantics, deterministic freeing
- [Modules and packages](/docs/book/packages/): organizing code, dependencies, publishing
- [Packages with native code](/docs/book/native-packages/): a Rust crate inside a package
- [Testing](/docs/book/testing/): `velt test`
- [Hot reload with `velt dev`](/docs/book/hot-reload/): edit a running server

When you need the precise rules, go to [the Reference](/docs/reference/); for module
APIs, to [the standard library](/docs/std/).
