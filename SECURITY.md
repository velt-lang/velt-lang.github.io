# Security policy

This repo holds the source for the Velt website at <https://veltlang.com/>: a static site with no server, no accounts and no user data.

## Vulnerabilities in Velt itself

For the compiler, runtime, standard library, package manager or language server, follow the
[Velt security policy](https://github.com/velt-lang/velt/security/policy) and report privately
through [velt-lang/velt's private vulnerability reporting](https://github.com/velt-lang/velt/security/advisories/new).

## Vulnerabilities in this site

Please **do not open a public issue**. Report it privately through
[private vulnerability reporting](https://github.com/velt-lang/velt-lang.github.io/security/advisories/new)
for this repository: for example a script injected into a page, a compromised dependency in the
build, or an install command on the site that points somewhere it shouldn't.

Include the affected URL, what you observed and how to reproduce it. We aim to acknowledge
reports within a week.
